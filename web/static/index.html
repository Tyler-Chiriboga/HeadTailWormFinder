🔲 Tile QC View

Quick visual review of all worms:

  • Press G or click 🔲 Tile to open grid view
  • Choose grid size (2x2 to 6x6) for overview
  • View options: Cropped, Masked, or Straightened worms
  • Click any tile to select that worm and return to main view
  • Use ←/→ to navigate pages

🛠️ Workflow Guide

  1. Open a folder with video files using the 📁 button
  2. Run detection with 🔍 Detect to find worms automatically
  3. Select a worm by clicking its box or in the sidebar
  4. Draw head/tail using H and T modes (toggle Box/Line with L)
  5. Run segmentation with ✂️ Segment for pixel-perfect masks
  6. Refine masks with the brush tool if needed
  7. Use Tile View (G) for quick QC review of all worms
  8. Mark as QC'd when satisfied with all annotations
  9. Save your work with Ctrl+S

🔍 Batch Detection

Process multiple videos at once:

  • 🔍 Detect & Segment Folder - Process all videos in current folder
  • 🚀 Batch Detect - Opens modal with options for folder or entire project
  • Skip already QC'd videos or those with existing detections
  • Auto-runs SAM segmentation on each detected worm

✅ Quality Control (QC)

Track which videos have been reviewed:

  • Click ✅ Mark as QC'd when you've verified all annotations
  • QC'd videos show a green checkmark in the sidebar
  • QC status is saved with annotations and tracked in exports
  • Batch detection can skip QC'd videos automatically

🖌️ Brush Refinement

Use the brush tool to refine segmentation masks:

  • 🖌️+ Add - Paint to add pixels to the mask
  • 🖌️- Remove - Paint to remove pixels from the mask
  • Select which mask to edit (worm/head/tail) in the brush controls
  • Adjust brush size with the slider or [/] keys
  • Click Apply to save changes or Cancel to discard

📊 Export Options

Export your data in multiple formats:

  • 📊 Excel/CSV Export - Spreadsheet with annotations and statistics
    • Project Export - Single file with all data
    • Per-Chip Export - Separate file for each chip/folder
    • Includes project and chip summaries with health statistics
  • 🤖 Training Dataset Export - YOLO format for AI model training
    • YOLO Detection format (bounding boxes)
    • YOLO Segmentation format (polygon masks)
    • Configurable train/val split (splits by video)
    • Filter by QC status, censored worms, and mask availability
    • Generates ready-to-use dataset with data.yaml

🩺 Health Classification

Worms are automatically classified based on health score:

  • Healthy - Score < 0.5 (shown in green)
  • Leaky - Score ≥ 0.5 (shown in red)
  • Health scores are computed by a CNN classifier
  • Mark worms as Censored if they should be excluded from analysis

👁️ Right-Click Menu

Right-click on any box to access quick actions: segment, re-segment, delete mask, redraw box, censor/uncensor, or delete worm.

📝 Tips

  • Use Batch Detect to process entire folders or projects
  • Mark videos as QC'd to track your progress
  • Each worm can only have one head and one tail
  • Zoom in for precise annotations
  • Use "Selected Only" view to focus on one worm
  • Auto-detection runs when navigating to a new folder
  • Export training datasets to train your own YOLO models
