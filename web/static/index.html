🛠️ Workflow Guide

  1. Open a folder with video files using the 📁 button
  2. Run detection with 🔍 Detect to find worms automatically
  3. Select a worm by clicking its box or in the sidebar
  4. Draw head/tail using H and T modes (toggle Box/Line with L)
  5. Run segmentation with ✂️ Segment for pixel-perfect masks
  6. Refine masks with the brush tool if needed
  7. Save your work with Ctrl+S

🖌️ Brush Refinement

Use the brush tool to refine segmentation masks:

  • 🖌️+ Add - Paint to add pixels to the mask
  • 🖌️- Remove - Paint to remove pixels from the mask
  • Select which mask to edit (worm/head/tail) in the brush controls
  • Adjust brush size with the slider or [/] keys
  • Click Apply to save changes or Cancel to discard

👁️ Right-Click Menu

Right-click on any box to access quick actions: segment, re-segment, delete mask, redraw box, or delete worm.

📝 Tips

  • Use "Detect All" to batch process all videos at once
  • Each worm can only have one head and one tail
  • Zoom in for precise annotations
  • Use "Selected Only" view to focus on one worm
